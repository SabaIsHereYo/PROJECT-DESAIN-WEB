## 🚀 Apa itu IndieArc?

IndieArc dirancang sebagai prototipe website berbasis HTML dan CSS yang mengintegrasikan beberapa kebutuhan dalam ekosistem game indie. Fitur-fitur utamanya dikelompokkan ke dalam empat bagian, yaitu portal berita dan toko game, pusat acara dan Game Jam, pasar aset game, serta dashboard pengembang dan riwayat transaksi.

---

## ✨ Fitur-Fitur Utama Website

### 1. 🛍️ Toko Game & Portal Berita Global (`Index.html`)
* **Global News Spotlight:** Banner berita utama yang menyajikan liputan mendalam, *developer story*, pengumuman demo, *devlog*, hingga festival game indie.
* **Tautan Eksternal (External Store Links):** Integrasi tautan langsung ke toko resmi seperti Steam dan itch.io.
* **Toko Game Langsung (Direct Purchase Store):** Katalog game buatan developer lokal yang dipublikasikan langsung di platform IndieArc.
* **Label Demo Game (Game Demo Badge):** Penanda visual khusus untuk membedakan game yang menyediakan versi uji coba gratis.

### 2. 🏆 Pusat Acara & Game Jam (`indie.html`)
* **Banner Internal Game Jam:** Informasi event tahunan IndieArc lengkap dengan rincian tema, jadwal pendaftaran, mentorship, dan total hadiah.
* **Jadwal Acara Eksternal:** Pusat informasi kegiatan luar seperti Global Game Jam, webinar pengembangan game, dan meetup komunitas.
* **Informasi Pendaftaran:** Ringkasan status pendaftaran dan jadwal kegiatan agar pengguna mudah membandingkan event.

### 3. 📦 Pasar Aset Game (`assets.html`)
* **Kategori Aset Berbayar (Commercial Asset):** Paket aset 3D (FBX), sprite 2D, paket tekstur, dan UI kit dengan ketersediaan harga.
* **Kategori Aset Sumbangan (Donated / CC0 Asset):** Efek suara 8-bit, musik BGM, dan model gratis hasil sumbangan komunitas dengan kejelasan lisensi.
* **Penyaringan Aset CSS (Pure CSS Filter System):** Pemfilteran kategori aset berbayar/gratis secara instan tanpa pemuatan ulang (*reload*) halaman menggunakan pseudo-class `:checked`.

### 4. 📊 Dashboard Pengembang & Riwayat Transaksi (`dev.html`)
* **Kartu Pemantauan Analitik (Analytics Monitoring Cards):** Ringkasan statistik statistik total pemain aktif, jumlah unit terjual, dan pendapatan bersih.
* **Tabel Status Publikasi Game:** Rekapitulasi performa listing game (status published/draft, harga, dan statistik unduhan).
* **Tabel Aktivitas Pembeli Terbaru:** Log riwayat transaksi pembeli game/aset secara *real-time*.
* **Riwayat Pembelian Pribadi (Personal Purchase History):** Daftar riwayat transaksi pengguna beserta akses unduh file produk.
